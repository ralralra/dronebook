# 파이참 예제 코드 ('AI 드론 지능형 제어')

교재 'AI 드론 지능형 제어'의 예제 67개를 파이참(PyCharm)에서 바로 실행할 수 있게 파일로 옮긴 것입니다.
파일마다 맨 위에 예제 번호와 제목이, 맨 아래에 가상 드론으로 실행한 결과가 주석으로 적혀 있습니다.

## 쓰는 방법

**이 폴더를 그대로 프로젝트로 열기**

1. 이 저장소를 내려받습니다. GitHub 화면의 Code → Download ZIP을 누르고 압축을 풉니다.
2. 파이참에서 파일(File) → 열기(Open)를 누르고 이 `pycharm` 폴더를 엽니다. 폴더가 그대로 프로젝트가 됩니다.
3. 인터프리터를 정하라는 안내가 나오면 사용자 지정 환경(Custom environment)에서 유형을 Virtualenv로 두고 만듭니다.

**라이브러리 설치하기**

1. 파일(File) → 설정(Settings) → Python → 인터프리터(Interpreter)를 엽니다.
2. 패키지 목록 위의 + 단추를 누르고 `codrone-edu`를 검색해 패키지 설치(Install Package)를 누릅니다.
3. 같은 방법으로 `pandas`, `matplotlib`, `scikit-learn`을 설치합니다.

파이참은 판에 따라 메뉴 이름과 자리가 조금씩 다릅니다. 인터프리터 설정을 찾기 어려우면 설정 창의 검색 칸에 interpreter를 적습니다.

**실행하기**

1. 실행할 파일을 열고, 코드 위에서 마우스 오른쪽 단추 → Run을 누릅니다.
2. 실행한 결과를 파일 맨 아래의 '실행 결과'와 견주어 봅니다.

새 프로젝트를 처음부터 만드는 방법은 교재 '이 책의 구성'의 '예제를 실행하려면'에 있습니다.

## 알아 둘 점

- `drone_sim.py`(가상 드론)와 `font_setup.py`(한글 글꼴)는 예제와 같은 폴더에 있어야 합니다. 옮기거나 이름을 바꾸지 않습니다.
- 예제 가운데에는 앞 예제가 만든 파일을 읽는 것이 있습니다. 아래 표의 '비고'에 먼저 실행할 파일을 적었습니다.
- 실기체로 옮길 때는 첫 줄 `from drone_sim import *`를 `from codrone_edu.drone import *`로 바꾸고, `sim_`으로 시작하는 줄을 지웁니다.
- 예제를 실행하면 `mission.json`, `flight_wind0.csv`, `path_by_wind.png` 같은 파일이 이 폴더에 생깁니다. 지워도 다시 실행하면 만들어집니다.
